# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/yoink-labs/split/security/advisories/new) (**Security → Report a vulnerability**). Do not open a public issue, pull request or discussion for a vulnerability.

Include the affected component (iOS app, Worker API, CLI or MCP server), steps to reproduce and the impact you observed. We aim to acknowledge reports within a few business days and will keep you updated until a fix ships.

## Scope

In scope: this repository's code and the production Split API at `split-api.yoinklabs.dev`. Please test only against your own account and data, and do not run denial-of-service, spam or social-engineering tests.

## Supported versions

Only the latest App Store or TestFlight build, the current Worker deployment and the latest CLI release receive security fixes.
